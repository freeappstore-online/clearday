# ClearDay

**Track the days since you quit any habit. Calm, private, and fully offline.** A free app on [FreeAppStore](https://freeappstore.online), live at https://clearday.freeappstore.online.

## Develop

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # production build in web/dist
fas check     # FreeAppStore compliance checks
```

Pushes to `main` auto-deploy via GitHub Actions.
