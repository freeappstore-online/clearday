# ClearDay

**Coming soon — track the days since you quit any habit. Calm, private, offline.** A free app on
[FreeAppStore](https://freeappstore.online), live at https://clearday.freeappstore.online.

Right now this is a shell: it lists the planned features, but none of them work yet. Progress is
tracked in
[freeappstore-online/platform#195](https://github.com/freeappstore-online/platform/issues/195).

## Develop

```bash
pnpm install
pnpm dev      # local dev server
pnpm build    # production build in web/dist
fas check     # FreeAppStore compliance checks
```

Pushes to `main` auto-deploy via GitHub Actions.
